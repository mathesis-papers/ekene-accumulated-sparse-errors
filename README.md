# Counterexamples to Ekene E.'s accumulated sparse-error conjectures and a sharp extension of Barron's bound

**Authors:** Haobo Ma, Wenlin Zhang

Ekene E.'s finite-dimensional and Hilbert-space conjectures in A bound on accumulated PSD contractions, MathOverflow question 509794, revision 2, paragraphs 1–2 (2 April 2026), are false: we construct equicorrelated counterexamples and give a sharp accumulated extension of Barron's pointwise approximation bound (1993, Lemma 1). The harmonic upper bound has sharp leading constant one, and the optimal pointwise squared-error envelope is 1/(1+sqrt(d))^2. The same errors are realized by uniform measures on unit vectors, with zero tails; one 64-atom example has total strictly between 1.431 and 1.432. A countably supported measure in a separable Hilbert space has a divergent accumulated squared-error series.
